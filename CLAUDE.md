# Living Earth: working agreements

## Filing unit materials in Google Drive

Whenever we make unit materials (slides, printables, student notebook, teacher
notebook, teacher key and teacher pages, assessments and their keys, and any
associated documents, videos, or pictures), file every piece in the matching
unit folder under the CP 26-27 curriculum folder:

- Root: "LE CP 26-27" (`1aOwJ0mLbd-xJ79MPERtyIjrGLIFV20yk`)
  https://drive.google.com/drive/folders/1aOwJ0mLbd-xJ79MPERtyIjrGLIFV20yk
- Unit folders sit directly under the root, for example:
  - Unit 1.3 Sugar to Structures (LS1-6): `1yvFf77Y0j9kt4Do091Hh39gqWNj5G00x`
  - Unit 2.1 DNA to Proteins (LS1-1): `1-ouynhFQDpnWGAXcirLho4PaPH90nUAe`
  - Unit 2.2 Inherited Instructions (LS3-2): `18O5hdyMhkl8-VJmOLhearBc-oJUDG_bI`
  - Unit 3.1 Age of the Earth (ESS1-5): `15pr6CnPU5l2DENK-ARq7513pY45-GDmB`

Inside a unit folder, use the Unit 2.1 layout:

| Subfolder | What goes in it |
|---|---|
| Slides | Daily slide decks (one per lesson) |
| Student Notebook | Student notebook PDF and student printables PDF |
| Teacher | Teacher notebook, printables teacher key, teacher pages, assessment keys and review materials |

Add a subfolder (for example "Assessment" or "Media") when a unit has videos,
pictures, or files that do not fit those three.

Rules:

- Edit existing Drive files in place. Do not create duplicates; keep the same link.
- If a subfolder is missing, create it inside the unit folder.
- Do not file things in the "(2027-28)" decks or the "Do not use ..." folders.
- Canvas quizzes live in Canvas, so also file their teacher key and any QTI
  package in the unit's Teacher folder.
- After filing, tell the user which folder each item went into.
