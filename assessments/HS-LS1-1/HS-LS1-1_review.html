Key ideas to know

  1. DNA is a double helix made of nucleotides. Each nucleotide has a sugar, a phosphate, and a base (A, T, C, or G).
  2. A gene is a section of DNA with the instructions for one protein.
  3. Copy, then read. A gene's message is copied, and the copy is read to link amino acids in order into a chain. The DNA itself stays protected.
  4. The order of bases sets the order of amino acids, and the amino acid chain makes the protein.
  5. One base change can change one amino acid, which can change how a protein works. Not every change matters.
  6. All your cells have the same DNA, but each kind of cell uses different genes, makes different proteins, and so has a different job.
