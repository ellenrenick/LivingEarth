## Part 1: Vocabulary Matching

Match each term with its best definition. Some definitions will not be used.

| Term | Correct definition |
| --- | --- |
| DNA | The molecule in a cell that stores the instructions for building proteins, shaped like a twisted ladder |
| Nucleotide | One of the repeating building blocks of DNA, made of a sugar, a phosphate, and a base |
| Gene | A section of DNA that holds the instructions for one protein |
| Base sequence | The order of the bases (A, T, C, G) along a strand of DNA |
| Amino acid | One of the small building blocks that are linked in a chain to make a protein |
| Protein | A large molecule made of a chain of amino acids that carries out jobs for the cell |

*Distractors (unused):* A group of similar cells that work together to do a specific job; The process by which a cell divides to make two new cells

## Part 2: Multiple Choice

### 1. Modeling DNA (DOK 2)

A student builds a model of DNA from paper and pipe cleaners. Which set of features must her model show to represent DNA **correctly**?

A. A single straight strand made of amino acids joined together  
B. A ball-shaped molecule made of phosphate groups with no bases  
C. Two strands twisted together, each made only of sugar molecules  
D. Two strands twisted into a double helix, built from repeating nucleotides, each with a sugar, a phosphate, and a base  ✅  

**Answer: D** — DNA is a double helix built from nucleotides. Each nucleotide has a sugar, a phosphate, and a base. Amino acids make up proteins, not DNA.

### 2. Reading a gene (DOK 2)

The code table below shows the amino acid that each DNA triplet (three bases in a row) calls for.

| DNA triplet | Amino acid | DNA triplet | Amino acid |
| --- | --- | --- | --- |
| ATG | Met | GAG | Glu |
| CTG | Leu | GTG | Val |
| TTT | Phe | GAC | Asp |
| CCT | Pro | GGC | Gly |

A gene has the base sequence **ATG CTG TTT CCT**. Which chain of amino acids will be built from this gene?

A. Met – Phe – Leu – Pro  
B. Met – Leu – Phe – Pro  ✅  
C. Met – Leu – Phe – Gly  
D. Pro – Phe – Leu – Met  

**Answer: B** — The triplets are read in order from the start: ATG = Met, CTG = Leu, TTT = Phe, CCT = Pro. The base sequence sets the amino acid order.

### 3. One base changes (DOK 2)

Use the code table.

| DNA triplet | Amino acid | DNA triplet | Amino acid |
| --- | --- | --- | --- |
| ATG | Met | GAG | Glu |
| CTG | Leu | GTG | Val |
| TTT | Phe | GAC | Asp |
| CCT | Pro | GGC | Gly |

A gene normally reads **ATG GAG GAC**. In one person, a single base changes and the gene reads **ATG GTG GAC**. Which statement **best** describes the effect?

A. The second amino acid in the chain changes from Glu to Val, so the protein that is built is different and may work differently.  ✅  
B. All three amino acids change, because one base change affects the whole chain.  
C. The protein is exactly the same, because only one base changed.  
D. No protein is built, because every change in DNA stops protein building.  

**Answer: A** — GAG calls for Glu and GTG calls for Val. One changed base changed one amino acid. A different amino acid chain can fold or work differently.

### 4. Copy, then read (DOK 2)

A student compares a cell to a kitchen. The recipe book is kept safe on a shelf and never leaves it. The cook makes a copy of one recipe, takes the copy to the counter, and follows it to make a dish.

Which statement **best** matches this to how a cell uses a gene?

A. The amino acids are copied, and the copies are read to build DNA.  
B. The whole DNA molecule leaves the nucleus and is taken apart to make a protein.  
C. The gene's message is copied, and the copy is read to link amino acids into a protein; the DNA itself stays protected in the nucleus.  ✅  
D. The protein is copied into new DNA, which is then read.  

**Answer: C** — A gene's message is copied and the copy is read to build the amino acid chain. This keeps the original DNA safe.

### 5. Same DNA, different jobs (DOK 3)

A biologist studies two types of cells from the same person. Each type of cell contains genes 1, 2, and 3. She measures which proteins each type of cell makes:

| Cell type | Genes in the cell | Proteins the cell makes |
| --- | --- | --- |
| Type X | 1, 2, 3 | Protein 1, Protein 2 |
| Type Y | 1, 2, 3 | Protein 2, Protein 3 |

Which explanation **best** accounts for the data?

A. Both types of cells have all the genes, but each type uses a different set of genes to build proteins, so each type has different proteins that do different jobs.  ✅  
B. Type Y lost gene 1 and Type X lost gene 3, so they cannot make the other proteins.  
C. Type X and Type Y must have different DNA, because they make different proteins.  
D. Proteins in a cell are made without using DNA, so DNA does not affect cell jobs.  

**Answer: A** — Every cell has the same genes, but cells use different genes. The proteins a cell makes give it its specialized job.

### 6. Which statement is correct? (DOK 2)

Which statement **best** describes the relationship among DNA, proteins, and the functions of a cell?

A. Proteins determine the base sequence of DNA, and DNA carries out jobs for the cell.  
B. DNA and proteins are the same molecule found in two different places.  
C. DNA carries out most jobs in a cell, and proteins store the instructions for DNA.  
D. DNA holds the instructions; those instructions determine the amino acid order of proteins, and the proteins carry out jobs for the cell.  ✅  

**Answer: D** — DNA stores instructions, the base sequence determines the amino acid sequence, and proteins do the work of the cell.

### 7. A case study (DOK 3)

Doctors study a condition caused by a single base change in one gene. They test three groups of people:

| Group | Gene version in the DNA | Protein made | Health effect |
| --- | --- | --- | --- |
| 1 | Normal | Works normally | No symptoms |
| 2 | Single base changed | One amino acid is different; the protein works poorly | Serious symptoms |
| 3 | Normal | Works normally | No symptoms |

Which conclusion is **best supported** by the data?

A. The protein changed first, and that caused the DNA to change.  
B. A change in the DNA changed the amino acid chain, which changed how the protein works, and that affected the body.  ✅  
C. Any change in a person's DNA causes symptoms.  
D. The symptoms are caused by the protein, not by the DNA, because DNA has no effect on proteins.  

**Answer: B** — The data link DNA to protein to body effect: the changed DNA built a different protein, which did not work well, and the person had symptoms.

### 8. Does every change matter? (DOK 3)

A student claims, “Whenever a base in a gene changes, the cell's protein will stop working.” A scientist records three different single-base changes in the same gene:

| Change | Amino acid chain | Protein works? |
| --- | --- | --- |
| A | Same as the normal chain | Yes |
| B | One amino acid is different | Yes |
| C | One amino acid is different | No |

Which statement **best** evaluates the student's claim?

A. The claim is supported, because all three changes affect the protein.  
B. The data cannot be used, because DNA never changes the protein.  
C. The claim is not supported: a base change can leave the protein unchanged or change it only slightly, and only some changes stop it from working.  ✅  
D. The claim is supported, because change C stops the protein.  

**Answer: C** — Changes A and B left the protein working, so a base change does not always stop it. What matters is whether the amino acid chain changes and how.

## Part 3: Free Response

### 1. A gene and a health condition (DOK 3, 4 pts)

A gene makes a protein that helps a cell move water. Doctors compare the DNA of a healthy person and a person with a condition that affects breathing.

| DNA triplet | Amino acid | DNA triplet | Amino acid |
| --- | --- | --- | --- |
| ATG | Met | GAG | Glu |
| CTG | Leu | GTG | Val |
| TTT | Phe | GAC | Asp |
| CCT | Pro | GGC | Gly |

|  | Healthy person | Person with the condition |
| --- | --- | --- |
| Base sequence of the gene | ATG CTG GAG GAC | ATG CTG GTG GAC |
| Protein works? | Yes | No (too little water moves) |

Write an explanation using **Claim, Evidence, and Reasoning**:
- **Claim:** Explain how the DNA difference caused the condition.
- **Evidence:** Use at least **two** pieces of data from the tables.
- **Reasoning:** Explain how the base sequence of a gene is copied and read to build an amino acid chain, how the change affects that chain, and how a different protein can change what a cell can do.

**4-point scoring rubric**

| Score | Level | Descriptor |
| --- | --- | --- |
| 4 | Advanced | Accurate claim that the single base change altered the amino acid chain, producing a protein that does not work, which led to the condition. Cites at least two accurate data points (the sequences differ at one triplet, GAG versus GTG; the amino acid changes from Glu to Val; the protein does not work). Reasoning describes copy-then-read from gene to amino acid chain, links the base sequence to the amino acid order, and explains that a different chain can make a protein that works differently so the cell cannot do its job. |
| 3 | Proficient | Accurate claim and two accurate data points. Reasoning links the base change to a different amino acid and to a protein that works differently, but leaves out one piece (for example, copy-then-read, or how the protein affects the cell). |
| 2 | Developing | Claim is partly correct (for example, "the DNA is different") without linking to the protein. One data point or inaccurate use of data. Reasoning is vague. |
| 1 | Beginning | Claim is wrong or missing. Little or no data. Reasoning shows a major misconception (for example, the protein changes the DNA). |
| 0 | No response | Blank or off-topic. |

**Grading notes**

- Key data: GAG (Glu) in the healthy gene versus GTG (Val) in the other; all other triplets are the same; the protein works in one and not in the other.
- Look for the idea of copy-then-read, and a link such as base sequence determines amino acid order, which determines the protein.
- Do not require the names mRNA, tRNA, ribosome, or any steps of protein synthesis; they are outside the HS-LS1-1 assessment boundary.
- Do not require the 3-D shape of the protein or its exact function; both are outside the boundary.
- Common misconception: a protein can change DNA, or DNA does the work of the cell.

**Exemplar response (score 4):** The condition happens because one base in the gene changed, which changed one amino acid in the protein so that it no longer works. The healthy gene reads ATG CTG GAG GAC and the other reads ATG CTG GTG GAC; the third triplet changed from GAG, which calls for Glu, to GTG, which calls for Val, and the protein no longer works. A cell copies the message of a gene and reads the copy to link amino acids in order, so the base sequence sets the amino acid order. When one amino acid is different, the chain can build a protein that works differently. Here the protein cannot move enough water, so the cell cannot do its job and the person has symptoms.

### 2. Same DNA, different cells (DOK 3, 4 pts)

A student says, “If all my cells have the same DNA, then all my cells must do the same job.” A teacher shows her this data about two types of cells from one person:

|  | Cell type P | Cell type Q |
| --- | --- | --- |
| Genes in the cell (DNA) | Genes 1, 2, 3, 4 | Genes 1, 2, 3, 4 |
| Proteins the cell makes | Proteins 1 and 2 | Proteins 3 and 4 |
| Main job | Carries signals | Squeezes to move the body |

- **Evaluate** the student's statement using at least two pieces of data.
- **Explain** how the DNA, through proteins, gives these two types of cells different jobs.
- **Predict** what would happen to the job of Cell type Q if the gene for Protein 3 had a base change that stopped Protein 3 from working. Explain your prediction.

**4-point scoring rubric**

| Score | Level | Descriptor |
| --- | --- | --- |
| 4 | Advanced | Evaluates the statement correctly: the first part is supported (same genes) but the conclusion is not (different jobs), citing at least two data points. Explains that the cells use different genes, so they build different proteins that carry out different jobs. Predicts that Cell type Q would not do its job well or would lose it, linking the changed gene to the changed protein and then to the job. |
| 3 | Proficient | Evaluates correctly with two data points. Explains that different genes lead to different proteins and jobs. Prediction is correct but the link from gene to protein to job is thin. |
| 2 | Developing | Partially evaluates (for example, says the student is wrong without evidence). Explanation says cells have different DNA, or says different proteins without linking to the genes used. Prediction is vague. |
| 1 | Beginning | Repeats the student's statement or shows a major misconception (for example, each cell has different DNA). Little evidence. |
| 0 | No response | Blank or off-topic. |

**Grading notes**

- Key data: both cells have genes 1 to 4; P makes proteins 1 and 2, Q makes proteins 3 and 4; the jobs differ.
- The idea to look for: same DNA, different genes used, different proteins, different jobs.
- Do not require names of real cell types, tissues, or body systems; they are outside the HS-LS1-1 assessment boundary.
- Common misconception: cells that do different jobs have different DNA.

**Exemplar response (score 4):** The student is right that the cells have the same DNA, since both have genes 1, 2, 3, and 4, but she is wrong that they must do the same job. Cell type P makes Proteins 1 and 2 and carries signals, while Cell type Q makes Proteins 3 and 4 and squeezes to move the body. Each cell uses a different set of genes, so each builds different proteins, and the proteins carry out each cell's job. If the gene for Protein 3 had a base change that stopped Protein 3 from working, Cell type Q would not be able to do its job well, because the changed gene would make a protein that does not work and Q depends on that protein.
