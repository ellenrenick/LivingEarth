# Review sites (intervention before reassessment)

Interactive, self-contained review pages for the end-of-unit tests (CSAs). Each page has key ideas, vocabulary cards and matching, practice with instant feedback, a model-reading section, written answers with a self-check list and sample answer, and a ready check. Progress saves in the student's browser.

| Unit | Page |
| --- | --- |
| 1.1 From Cells to Organisms (HS-LS1-2) | `HS-LS1-2/HS-LS1-2_review_site.html` |
| 1.2 Cell Energy & Carbon (HS-LS2-5) | `HS-LS2-5/HS-LS2-5_review_site.html` |

Unit 1.3 (HS-LS1-6) already has its own review page in `HS-LS1-6/`.

All practice questions are new scenarios, so they do not give away the CSA or the reassessment.

To change content, edit `units.py` (content) or `engine.css` / `engine.js` (look and behavior), then run `python3 build.py`.
