Key ideas to know

  1. Genetic variation is differences in genes among the individuals of a population.
  2. New combinations: each sex cell gets one allele of each gene, and fertilization joins two sex cells at random. Siblings get different mixes of the same alleles.
  3. Copying errors: when DNA is copied, a mistake can change a base. Each child has some new changes that neither parent has.
  4. Environmental mutations: UV light, radiation, and some chemicals can change DNA.
  5. A mutation is passed on only if it is in a cell that makes sex cells. A mutation in a skin cell is not inherited.
  6. To decide the source of a variation, use data: if both alleles were already in the parents it is a new combination; if the sequence is in neither parent it is a mutation.
